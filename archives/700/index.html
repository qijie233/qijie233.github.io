Self-Hosted meting-api (with NetEase Cloud VIP)

Qijie
2024-11-13
Tech Notes
Frontend, Website

API address: https://api.qijieya.cn/meting/

Parameter reference
server: data source
     netease NetEase Cloud Music (default)
     tencent QQ Music
Note: already migrated to the Hangzhou server, so domestic resolution speed ++++
Supports parsing NetEase Cloud Music VIP songs
type: type
     name song name
     artist artist
     url link
     pic cover
     lrc lyrics
     song single track
     playlist playlist
id: type ID (cover ID / single track ID / playlist ID)

This site's meting-api provides free NetEase Cloud VIP song parsing (NetEase Cloud Music musicians)

High availability of the API isn't guaranteed, but I'll fix it promptly whenever it goes down, since the site owner uses it too
