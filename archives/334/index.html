Qijie

Tech Notes
Customization, Linux

Preface

My view on customization is actually this: be as retro and plain as possible — performance comes first.

In KDE, the thing that eats the most performance is none other than kwin_x11’s compositor. This article first covers how to “kill” kwin_x11’s compositor, then moves on to sharing themes.

“Killing” KWin’s compositor

Open System Settings and do as shown:

Uncheck the box at red marker 3, then click Apply in the bottom right corner.

Here we’ll pick the less resource-hungry compositor: compton

Install command (Debian-based systems, for example)

Then do as shown

Choose Add Application

After adding compton, just edit it as shown

Note: On KDE 5.27+ you can’t use compton -b; use compton instead.

Once you confirm, log out and log back in, and you’ll see the performance-hungry compositor has become the compton compositor — no frosted glass (that stuff eats your GPU) or other fancy features.

Misc thoughts

Using i3wm is very unfamiliar at first (especially that pile of headache-inducing shortcuts), but as you keep at it (and get used to each other), you’ll find that i3wm gets smoother and smoother the more you use it — windows become much easier to find, unlike traditional stacking window managers like Windows, where one window piles on top of another until they’re hard to find and your blood pressure goes up.

i3wm on KDE uses far fewer resources than KWin_x11, and can win you an extra 1~14fps in some games.

What? You want that kind of window manager on Windows too? Fine, fine — GitHub actually has a corresponding project, portal here.
