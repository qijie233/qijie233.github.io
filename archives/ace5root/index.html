OnePlus Ace 5 Root Notes

Qijie
2025-02-26
Life & Misc › Tech Notes
Android, Daily Life, Flashing, Phone, Review

Before we start

There are really only three main reasons I chose the OnePlus Ace5 as my new phone

  • Unlocking the BL is more convenient, no difficulty to it

  • More open kernel source code

  • The price isn't too high

Although the ACE 5 Pro does have the Snapdragon 8 Elite, the price is a bit too much for me to bear — 3299+

Approach

The mainstream options on the market are the Mask app (Magisk) and KernelSU

Let me start with the conclusion: I'm definitely one to chase the new stuff. I'd used KSU before and quite liked it, but it's a new framework after all, so it has some BUGs one way or another. Also, the very first thing I flashed on my ACE 5 PRO was KSU, and the biggest BUG was that the storage space displayed incorrectly

I bought the 512G phone, and a while after flashing it turned into 1T. This.......... although it doesn't affect usage, it just looks uncomfortable to me. The specific cause is that sparse files make it impossible for the system to recognize

It seems there's a way to solve it now?

So then I chose the Mask app

If you don't understand commands or don't know how to download the tools, go use the OnePlus All-in-One Toolbox

You're right: the OnePlus All-in-One Toolbox is a OnePlus phone toolbox independently developed by Daxia Amu. The toolbox is used for the OPPO sub-brand known as "OnePlus phones". Here, OnePlus phones trained by the OnePlus All-in-One Toolbox will be able to "ROOT more easily" and channel the power of flashing. You will play the role of a "flashing master", breaking through the hurdles during flashing, defeating bricking, stuck LOGO, endless reboots, and system file corruption that prevents booting, and recover the phone form you want———At the same time, you will gradually uncover the truth of "flashing".

Unlocking BL

Unlocking BL will lose all your data, so if you want to unlock, it's recommended to unlock it right after buying the phone

Out of the box you must enter the system to enable developer mode, then enable OEM unlocking and USB debugging

By the way, when you plug USB into a OnePlus phone there's a USB-purpose selection dialog; if you choose "Charging only" it will automatically turn off OEM unlocking and USB debugging..........

The Daxia Amu toolbox can do it directly — all right, that's it, click me!

ROOT

I won't go into the specific root process here; please see Magisk Chinese Site

As for boot.img and init_boot.img — how do you choose? The simplest rule: new phones use init_boot.img, old phones use boot.img

On hiding the environment

KSU does have modules that can hide the BL lock and TEE spoofing, but Magisk doesn't have such modules. TEE spoofing will make payment fingerprints unusable, but an lsp module fixes that and WeChat Pay fingerprints work the same way; the principle is that the module verifies your fingerprint and then automatically enters the password for you (what a plain automation)

Then another problem I've found so far is that the Electronic Tax Bureau app can't use fingerprint login

Guoji Tiexun is part of the Xiao Bu assistant's life services and can't be used normally (bound) after unlocking BL; there are related tutorials on Coolapk for the specific solution

System optimization

The following only applies to the OnePlus ACE 5

There aren't many modules; the thermal control module is mainly to unleash the charging rate.

Then there's Tombstone NoActive Pro, which is quite useful — one cup of milk tea's price, recommended. Its main job is to make background apps use 0 CPU to achieve a bit of power saving. If you don't want to use it, I've also packaged a module that fills in the tombstone for ColorOS systems; it's in the link.

For scheduling I use Scene8; HP mode works quite well. Of course you can also use Muyong's official-mod scheduling, but I personally don't like it much (it only supports 8g3 & 8e)

OK, modules done, then there's debloating. There isn't much worth debloating — these things only take up memory and basically don't use power, it's just that I don't use these features so I removed them. If you need them, search Coolapk for debloat lists or modules.

Background optimization — I highly recommend installing this one; after installing you don't need to configure anything either, and if you want to fiddle there's a manual inside. It basically never kills background apps, very useful.

lucky tool is by the developer Yiqingming; just search Coolapk yourself.

Then there's Thanox (The Overlord); what I mainly use is its scenario modes, for example suppressing QQ, WeChat, Douyin, Bilibili and other apps. Set up other things yourself if you need them. I've packaged it up, just restore and it works.

For QQ I recommend version 8.8.50; the 9.0 (NT) versions are all big power hogs, averaging 2.5W+
