About domains

I can offer you second-level domains under an ICP-registered domain

How to apply: email or join the QQ group

penacony.cn

This domain is ICP-registered as an enterprise on Tencent Cloud, with access registration at Alibaba Cloud

Meaning of the domain: Penacony, taken from the place name Penacony in Honkai: Star Rail

You can apply for any second-level domain, provided of course that it doesn't conflict with a third party.

APIs

NetEase Cloud Music

The API address is: https://163api.qijieya.cn/

As for what this API is mainly for, just click in and you'll see

MetingAPI

API address: https://api.qijieya.cn/meting/

参数说明
server: 数据源
     netease 网易云音乐(默认)
     tencent QQ音乐
支持解析 网易云音乐 VIP 歌曲
type: 类型
     name 歌曲名
     artist 歌手
     url 链接
     pic 封面
     lrc 歌词
     song 单曲
     playlist 歌单
id: 类型ID（封面ID/单曲ID/歌单ID）

This API comes with NetEase Cloud Music VIP; it can of course also parse QQ Music, though without VIP
Example

https://api.qijieya.cn/meting/?type=url&id=1969519579
https://api.qijieya.cn/meting/?type=url&id=416892104
https://api.qijieya.cn/meting/?type=song&id=591321
https://api.qijieya.cn/meting/?type=playlist&id=261936628

Note⚠️

163DownAPI & free player

About the website

Image hosting

Address: img.qijieya.cn

The whole thing is built on Lsky Pro

Backend storage is OSS, with a layer of Volcano Engine CDN on top, so the overall loading speed is really fast

This is an 8.2MB image — have a look at how fast it loads

https://oss.qijieya.cn/cos.jpg

Default storage capacity per user is 800MB

On rate limiting: if a single IP requests faster than 15MB/s, it will be throttled to 100KB/s

Cloud drive (already dead for now)
