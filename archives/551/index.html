A Weird Way to Use RAM: Turn It Into a Hard Drive!

Qijie
2024-02-01
Tech Notes
Linux, RAM

What would happen if you took memory, whose random read/write is faster than an ordinary hard drive, and used it to store things like a hard drive?

Taking Linux as an example, the author mounted part of the memory on his physical machine at ~/ramdisk, then used download tools like aria2 to drop videos, documents and other files in there, to see how it would actually turn out.

In Linux, tmpfs is a filesystem that treats part of the memory as a hard drive. In the case of unmounting it or rebooting and cutting the power, the data inside will disappear permanently (for a really long time!). (It’s memory after all)

Let’s Go!

1. Mount the Directory

Then you can cd into it and download some videos. When you see memory usage go up, that means the videos have been thrown into memory.

2. Let’s See the Effect

Opening a video file with vlc/mplayer, it opens a whole lot faster than a video on an SSD, and there’s absolutely no stuttering while watching.

Specific Use Cases

For example:

  • Can be used as /tmp to improve system performance
  • Put frequently read and written files into memory to improve actual runtime efficiency
  • If you have enough memory, the operating system can go in there too (Linux Live CD, WinPE, etc., or even a complete OS) — into the system in a second, apps open in a second
  • In-memory databases already exist, such as redis (the database used by projects like Yunzai)

There are plenty more uses waiting for you to discover.
