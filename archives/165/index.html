A Record of My 1Panel Experience (and the Pitfalls)

Qijie
2023-06-14
Tech Notes
BT Panel

Don’t Ask for Trouble and Trouble Won’t Find You

That saying is absolutely right

Last night, heaven knows what got into BT Panel: right after I installed the Alibaba Cloud OSS plugin, it popped up an error saying the BT Panel had crashed. I was at a loss for words — the Websites tab simply wouldn’t load. Fortunately the files were still accessible, so I backed up the site databases and got ready to reinstall the server. That’s when I remembered the 1Panel panel I’d seen before, and figured I’d give it a try.

[button color=”info” icon=”” url=”https://www.1panel.cn/“ type=”round”]1Panel official site[/button]

The Process + My Impressions (Only Half an Hour, Though)

The install was the classic one-liner, and it was pretty quick too (faster than BT Panel). Once I got in, I had exactly one impression: it looks good. The overall UI design is better than BT Panel’s ad-covered design by who knows how many times over. At that point I was delighted — could it be that BT Panel can finally be abandoned?!

So then I started installing the environment, but I couldn’t seem to find apache — only an all-in-one bundle that included Nginx. After installing that I went to install PHP, and absurdly enough, installing PHP requires setting up a separate environment, rather than installing it as software the way BT Panel does. Anyway, I configured a new environment, and once it was installed I started building the site. Then something that broke me happened: you can’t specify the site directory yourself, only the default one it gives you. Fine! I accepted that. When I migrated the files over to the default directory and opened the site, it showed me a PHP page. I was done with it. I fiddled around for ages and never got it working…….. For me, apart from the UI being attractive, there’s really nothing to say in its favour — the site-building experience is rather poor. And for site SSL, it can’t deploy Let’s Encrypt in one click the way BT Panel does; you have to import the certificate manually. I don’t use Let’s Encrypt myself, but that alone will strike a lot of people as inconvenient.

Switching Back to BT Panel

After resetting the server, I quietly chose BT Panel, but!!!!, **after BT Panel was installed, when I went to install MySQL it suddenly died — without any warning. Restarting the panel from the command line didn’t work either; it showed BT-Panal service startup faild (startup failed)

Alright, alright. Left with no choice, I rebooted, and the result was that **BT Panel told me

Good grief, it’s gone?!!!

I really was speechless. I reinstalled the system once more, praying that nothing would go wrong, and luckily this time everything went fairly smoothly with no major problems. Staring at the ads on the homepage, all I could do was put up with them helplessly, and in the end I successfully restored the site.

Closing Words

About this whole business, all I can say is, **this one is on BT Panel. From the first server reinstall to finally getting everything back, it took me about 4h. Actually it wasn’t fully restored……. I forgot to back up Alist (Qijie’s Little Site), so it had to be redeployed from scratch. After redeploying, it feels a bit prettier than the old one
