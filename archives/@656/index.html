Installing a Chinese Language Pack on Ubuntu (Command Line)

Qijie
2023-05-28
Tech Notes
Linux, Server, Ubuntu

Preface

When we happily start using the server we just bought, we find that the command-line prompts are all in English. We’re just about to type “help” to look up how a feature works, and… all English?! At a moment like this, installing a Chinese language pack on the server becomes important. Files containing Chinese characters also come out as garbled text, so there’s a need to set up a Chinese environment on Ubuntu Server. The concrete steps are below.

Install the Chinese language pack

sudo apt install language-pack-zh-hans
