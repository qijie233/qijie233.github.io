SSTV - 一种使用音频传输图片的方法以及特别用法

祈杰喵
2024-04-18
技术笔记
SSTV

介绍

SSTV，全称 Slow-Scan TeleVision（慢扫描电视），常见于业余无线电领域中。
这是一种始于20世纪中后期的传输图片的方法，到现在可以使用PC以及对应的软件编解码SSTV音频信号。

常用的调制方法有：Martin 1、Robot系列、PD系列等，不同的调制方法支持的分辨率与颜色不同。

更多有关SSTV的详细信息可以从搜索引擎中获取。

特点 & 特别用法

它的缺点就是模糊（分辨率低）、慢，不过可以将QR Code（二维码）编码为SSTV来无视模糊这一缺点。

将QR Code编码为SSTV音频信号后，可以以音频的形式发送二维码，

从而可以实现在某些Q群的Q群管家不允许发送链接和带二维码的图片的情况下发送“二维码”音频。

当然SSTV有些时候会作为游戏藏彩蛋的方式，例如在《Portal》游戏中，有以SSTV的形式出现的彩蛋（1代为收音机）

使用方法

在Linux中，可以使用QSSTV软件进行SSTV音频编解码，安装方法以Debian系为例：

该软件可以读取或写入音频文件，具体到 Options -> Configuration -> Sound 中可以设置音频输入输出选项。

当然Windows中也有处理SSTV的软件：MMSSTV，本文不作具体的介绍。

Decode 解码

使用 Receive 页，点一下即可读取音频或者监听电脑内播放的声音以读取SSTV音频

推荐将右边的Sensitivity调到“High”或“DX”。

可以按下下图按钮清除当前画面

在通过声卡设备内录解码的时候听音乐会对解码结果产生轻微的影响（干扰），实际上播放音乐时的共振峰很少覆盖到SSTV所识别的部分，所以影响可以说是有一些些的。（多了些噪点罢了）

如果实际解码的时候图片出现往一边倒的情况，建议勾选下图红框内的选项。（一般保持勾着就行）

Encode 编码

使用 Transmit 页，选择好mode并打开图片文件，设置好图片的填充方式即可点

编码的时候音箱会发出类似于以前的调制解调器的叫声，可以单独在音量那里调小声音（在输出到文件的时候不影响结果）。

大部分情况图片不需要太大，图片分辨率在1024x1024以下效果更佳。（大了会自动缩放分辨率以适应）

一般推荐使用图片填充方式“Fit” 和 使用Mode “PD120/180”或者“Martin 1”进行编码
