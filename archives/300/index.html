How to Deploy Miao-Yunzai

Qijie
2023-08-05
Tech Notes
Linux, Yunzai

Foreword

Miao-Yunzai, or Miao-Zai for short, is a modded version of Yunzai (v3).
Yunzai is a QQ bot, mostly used for looking up Genshin Impact related info.

The author of this post only uses Linux, so no Windows instructions are provided (just apply the same logic and you’re fine)

Requirements

Hardware Minimum Recommended
OS Linux or Windows 10+ Debian-based
CPU 1C (no sign or remote sign); 2C (local sign) 2C or more
RAM 1GB + 2GB +
Disk 20GB + 40GB +
GPU Not needed <_<
Software Version
nudejs(nodejs) v16+
redis-server (install directly)
git ^
python3 (now required by sqlite3) 3.8+
See install dependencies below for more -
