如何部署Miao-Yunzai

祈杰喵
2023-08-05
技术笔记
Linux, 云崽

前言

Miao-Yunzai 简称 喵崽，是 云崽(v3) 的魔改版本。
云崽 是QQ G7人，多用于查看原神相关信息。

本文作者只使用Linux，故不提供Windows相关（同理过去就行了）

配置需求

硬件 最低 推荐
OS Linux 或 Windows 10+ Debian系
CPU 1C (无或远程的sign);2C(本地sign) 2C以上
RAM 1GB + 2GB +
硬盘 20GB + 40GB +
显卡 不需要 <_<
软件 版本
nudejs(nodejs) v16+
redis-server （直接装）
git ^
python3（现在sqlite3要求必装） 3.8+
更多请看下面安装依赖 -
