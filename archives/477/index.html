Some Fun Things You Can Do with chroot

Qijie
2023-11-26
Tech Notes
Linux, Server

Introduction

chroot can be traced all the way back to the Unix era — a “nesting doll” used to isolate the file system for the sake of data security. What makes it different from that other nesting doll, the virtual machine:

  • A VM fully isolates (virtualizes) hardware, while chroot shares the Kernel, devices and their drivers, and the process space
  • Since chroot only isolates the file system while a VM has to emulate an entire hardware system, the overhead of the chroot doll is far lower than that of a VM
  • chroot can’t cross major architectures — to go from arm64 to x86_64 you need Exagear/Box64/qemu-user (the first two are arm64-only), and the translation overhead is significant

It requires root. On some Android phones that won’t give you root, you can only use proot.

chroot has a few uses:

  • Entering the Linux environment already on the machine from a Live CD (rescue system)
  • On top of that, repairing the bootloader or recovering a damaged system
  • Because it uses the host machine’s Kernel, you can even enter a Linux environment whose kernel is already damaged and “scrape by”. This site did that once: the Ubuntu 22.04 kernel that some provider shipped was unstable (probably because no SWAP was set, so the system kept getting blown up — though that cause is doubtful), so we simply booted into the rescue system, mounted the original partitions, chrooted in, then entered the “BT” panel and started the N(ginx) M(ySQL) P(HP) services to “scrape by”. And the server’s rescue system had blown up too (screwed all the way into a black hole).
  • Running a separate Linux environment on an Android phone
  • Customizing your own image — the author once built a Kali Linux of their own (but went back to the stock one for various reasons)
  • Isolating the file system a service lives in, so that even after the service is compromised there’s nothing it can do

etc.

chroot/proot on Android phones is the same idea, except /target isn’t allowed. With root, the recommended place is /data/linux; without root, just create a folder under Termux’s home directory. After that it’s a matter of finding a rootfs and extracting it in, and finally doing the steps above.

Misc

  • Some phones can use chroot to access the screen device and start a real X Window, but most phones can’t do that anymore.
  • The distro information that apps like the “BT” panel grab follows the information inside the doll
