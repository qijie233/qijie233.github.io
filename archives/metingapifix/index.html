Picking Up Where We Left Off

This time I mainly fiddled with the blurry album art problem, and also added call-count retrieval

Enjoy~

Fetching the Album Art

The project fetches images at 90*90 by default, which is why the album art you see on the player page is blurry

In the src/Meting.php file, the pic method is used to fetch album art, and it accepts a $size parameter (default value 90):

public function pic($id, $size = 90)

In the index.php file, the song2data function calls this method when handling image requests:

case 'pic':
    $data = json_decode($api->pic($id, 90))->url;
    break;

As you can see, the image size is currently set to 90. If you want to change the album art size, you need to modify this line in the index.php file.

Here's how to modify it:

  1. Open the index.php file

  2. Find the case 'pic': part in the song2data function

  3. Modify the $data = json_decode($api->pic($id, 90))->url; line, changing 90 to the size you want

Fetching the Call Count

This one is a bit more involved to add

Code added in the index.php file

Added the update_api_stats() function at the beginning of the file:

// API调用统计功能
function update_api_stats() {
    $stats_file = __DIR__ . '/cache/stats.json';
    

// 初始化统计数据
$stats = array(
    'total_calls' =&gt; 0,
    'today_calls' =&gt; 0,
    'last_call_date' =&gt; date('Y-m-d')
);

// 如果统计文件存在，读取现有数据
if (file_exists($stats_file)) {
    $stats_data = json_decode(file_get_contents($stats_file), true);
    if ($stats_data) {
        $stats = $stats_data;
    }
}

// 检查是否是新的一天
if ($stats['last_call_date'] != date('Y-m-d')) {
    $stats['today_calls'] = 0;
    $stats['last_call_date'] = date('Y-m-d');
}

// 更新统计计数
$stats['total_calls']++;
$stats['today_calls']++;

// 保存统计数据
file_put_contents($stats_file, json_encode($stats));



}

Where to put the stats function call

Put the stats function call after parameter validation, to make sure only API calls trigger the counting:

if (!isset($_GET['type']) || !isset($_GET['id'])) {
    include DIR . '/public/index.php';
    exit;
}


// 只有在API调用时才更新统计
update_api_stats();

Code added in the public/index.php file

Code that reads the stats data

Added PHP code in the HTML content to read the stats data:

<?php
// 读取API调用统计信息
$stats_file = DIR . '/../cache/stats.json';
$total_calls = 0;
$today_calls = 0;


if (file_exists($stats_file)) {
    $stats_data = json_decode(file_get_contents($stats_file), true);
    if ($stats_data) {
        $total_calls = isset($stats_data['total_calls']) ? $stats_data['total_calls'] : 0;
        $today_calls = isset($stats_data['today_calls']) ? $stats_data['today_calls'] : 0;


    // 检查是否是新的一天
    if (isset($stats_data['last_call_date']) &amp;&amp; $stats_data['last_call_date'] != date('Y-m-d')) {
        $today_calls = 0;
    }
}



}
?>

Code that displays the stats

Added HTML and CSS code to display the stats:

<div style="background-color: #f0f8ff; padding: 10px; border-radius: 5px; margin-bottom: 20px; font-size: 14px; width: 300px;">
    <h4 style="margin: 0 0 5px 0;">API调用统计</h4>
    <p style="margin: 3px 0;">累计调用: <strong><?php echo $total_calls; ?></strong></p>
    <p style="margin: 3px 0;">今日调用: <strong><?php echo $today_calls; ?></strong></p>
</div>

Data Storage

The stats are stored in the cache/stats.json file and contain the following information:

  • total_calls: total number of calls

  • today_calls: number of calls today

  • last_call_date: date of the last call

Summary of the Call Counting

Implementing API call counting mainly involves the following changes:

  1. Add the stats function and the call logic in index.php

  2. Add the stats reading and display code in public/index.php

  3. Use the cache/stats.json file to store the stats

These changes ensure that:

  • Only API calls get counted; visiting the homepage doesn’t count

  • The stats are displayed on the site’s homepage

  • The data is stored persistently in the cache directory

  • The daily stats reset automatically
