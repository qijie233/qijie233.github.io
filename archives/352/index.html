Basic Approach to Installing Kali, Ubuntu and Other Debian-Based Linux Distros

Qijie
2023-08-23
Tech Notes
Linux

Preface

This article is mainly about the approach, so there are almost no installation screenshots. (Actually, the author was just too lazy to install them one by one and screenshot each one.)

Linux can be installed on all kinds of devices, from supercomputing centers (not covered here) all the way down to a Raspberry Pi the size of a bank card…

From small to large, let’s go through the install approach.

Before You Install

Raspberry Pi: an SD card of 32GB or more, high speed (100MB/s is better)

Android phone: rooting it makes things easier

Various TV boxes: prepare your own firmware (you know the drill, not covered here)

Computer: a USB drive of 8GB or more (this is mainly what this article covers)

Starting with the Raspberry Pi

First you need to download the image; the official RaspiOS is best.

That site comes with its own writing tool.

After writing, use raspi-config to configure it — or configure everything in the official writing tool before writing (recommended; then you don’t have to use the built-in pi user).

Android Phones

No root: use Termux + nesting (proot)

You can use the tmoe script to simplify things

With root: use Linux Deploy for nesting (chroot)

After installing the app, configure first, then hit “Install”.

Remember to use domestic mirrors to speed up deployment.

Computers

If you just want to try Linux out, you can use a virtual machine or set up a dual boot.

Image download: Tsinghua mirror

Take out the USB drive we mentioned earlier. Note: making it a system disk will wipe all data on the drive, so please back it up before starting your “performance”.

Use dd and similar tools to write the image to the USB drive.

Step 1: Boot into the Linux Installation Media

If it’s a virtual machine you don’t need a USB drive at all; just use the iso image.

If it’s not a VM, plug the USB drive into a USB port on the computer (3.0 recommended), then get into UEFI/BIOS to boot from it.

Handling Common Errors

Failed to mount the installation medium:

That’s a Debian Installer thing.

But you can boot the ISO directly through a special GRUB2 (Ventoy).

Step 2: Preparation Steps

If nothing goes wrong, you’ll get a screen along the lines of Welcome to [distro name],

or a language selection screen.

For the language, it’s best to choose Chinese (Simplified).

For the keyboard layout, please choose American English or Chinese.

Hostname: put whatever you like here, English is best

Domain (if there is one): I recommend WORKGROUP (supposedly it connects to Windows machines better) or leave it empty

Username: whatever you like, but follow these rules: start with a lowercase letter, and only use characters from [0-9][a-z][A-Z].

Password: follow this article

Step 3: Disk Partitioning

This is the most important part; you have a chance to regret it before you hit Confirm.

Data is priceless, so be careful!

For disk initialization, use GPT whenever you can, unless it’s an old computer that needs MBR (ancient).

For a single disk, I recommend just one / (root partition).

SWAP will be allocated automatically (on Ubuntu and the like).

Also, if you have an SSD + HDD, you can do this:

SSD: / for all of it

HDD: /home for all of it

That way you make the most of your disk space.

Once you’ve confirmed everything, you can start writing to the disk and installing base-system (the basic system, no GUI).

Step 4: Installing the System

Use a network mirror (if there is one), and use domestic mirrors wherever possible.

Try to tick the options related to using proprietary firmware or drivers; that’s useful for Nvidia cards (Ubuntu installs proprietary drivers automatically during setup).

Debian/Kali and the like have package group selection (handled by tasksel); tick the software you need there.

KDE is the desktop environment I recommend;

Wayland is not recommended.

After you hit “Install”, it’s a long stretch of downloading and installing (depending on network speed and disk speed)~

Here I choose to take out my phone,

Genshin, launch!

By the time the four daily commissions are done and the resin is spent, it should be almost installed (that’s how it was on my end).

Step 5: Writing the Bootloader

You must use GRUB to boot, otherwise you can’t Linux, launch!

Mission Accomplished? Or All for Nothing?

If nothing goes wrong, you’ll see a shiny brand-new Linux desktop (if you installed a GUI).

Failures are mostly network (package download) problems; if it doesn’t work, just start over from that step.

Once you get past this step, you can reboot into your freshly installed Linux.

Please install the packages that match your actual use case.

I recommend installing common tools like vim and git.
