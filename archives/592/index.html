Introducing LLOneBot

LLOneBot uses LiteLoader to operate an account unattended, and can connect to the bot through the OneBot protocol.

Compared with debugging the Sign-related so with unidbq, which brings low freeze resistance,

since LLOneBot only controls the client’s sending and receiving of messages, its Effect RES is obviously higher than icqqjs’s. (Honkai: Star Rail cameo)

Installing and Using LLOneBot

Starting with LiteLoader

First, get LiteLoader from here, and follow the tutorial there to install LL.

(On Windows the one-click script is recommended; on Linux you’ll need to mind the file permissions.)

If “LiteLoaderQQNT” shows up in the client settings, that means the installation succeeded.

Adding the LLOneBot Plugin

Get the plugin archive from here, and just extract its contents into LiteLoader安装目录/plugins/LLOneBot（没有就建个文件夹）.

Then restart the client; seeing the word “LLOneBot” in the settings means the installation succeeded.
