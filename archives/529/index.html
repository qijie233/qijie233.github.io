New to Programming? Where Should You Start?

Qijie
2023-12-16
Tech Notes
C++, JavaScript, Programming, Python

Getting to Know Programming

From the most primitive and complex machine language to the various high-level languages that fit human thinking better today, almost every programming language exists to serve human computation tasks or human convenience. So let’s first get to know what programming languages there are!

A Brief Intro to Major Programming Languages

Python

It’s an interpreted programming language with a huge number of development libraries (managed with pip or conda), such as pytorch and TensorFlow (deep learning) and scipy (scientific computing).

Coding efficiency is fast, but execution efficiency is still a bit worse than C/C++ (except for the computations in deep learning libraries like PyTorch, since those libraries are ultimately written in C/C++).

Source files end in .py, and the simplest way to run such a program is python 程序.py — though it’s best to check the README.md to see how these programs should be run.

C/C++

This is the language I most recommend learning first. C/C++ is a low-level language among high-level languages (not that C/C++ users are superior — “high-level” means close to how humans think, “low-level” means close to how computers compute). It emphasizes types, and also provides bitwise operators for reading and writing binary stuff like memory…

Unlike other programming languages, it has to be compiled and linked before it can run. Usually these steps are managed with make (big projects do this; for small programs, just g++ 源文件.cpp -o target).

They say that when using gcc/g++, you can inhale oxygen (-O2) to raise the run speed, or inhale ozone (-O3) to raise it a lot, though that restricts the platform/architecture it can run on. (joking)

Honestly, C/C++ is the father of interpreted languages like Python, and languages such as JavaScript and PHP use C/C++ operator and control-statement syntax. So learning C/C++ first gives you a considerable advantage when switching to JS, PHP and the like (what you learn is the fundamentals and the basic ideas).

C++ differs from C in that it adds class (classes, which allow OOP (object-oriented programming)), templates and other features that make OOP more convenient.

Apart from BASIC, C/C++ is also one of the languages that still keeps the goto statement today (almost every other programming language has removed this tumor).

Javascipt

It’s also an interpreted language, used to add client-side (frontend) logic to HTML/PHP documents and, together with CSS, to build more attractive dynamic websites. There’s also nodejs for the backend — a typical example is Yunzai…

The best language in the world! (joking)

PHP scripts can be embedded in html files to build dynamic pages, and it has a very rich function library plus more convenient database connectivity.

Shell

It mainly comes in Bash, which is common and widely used, and the more powerful zsh (which supports floating point). Unlike other programming languages, it executes line by line and separates the program from its arguments with spaces.

It also borrows operators and control statements from C/C++.

Starting with C/C++ (Recommended)

First of all, I really don’t recommend reading Lao Tan’s “Little Red Book / Little Green Book” (I own his green book too, and I’m one of its “victims”), because the environment these books use is extremely ancient (Turbo C and Borland C++, antiques from the DOS era). Second, “ignore the warnings for now” can bring immeasurable disasters to development. And the variable naming is a total mess (int x,y,z;//这是最为忌讳的命名方式，因为其他人不理解你把这个变量命名为单个字母是什么意思).

Also, don’t decide that C/C++ is hard the moment you start (most likely because you were influenced by the ancient content in Lao Tan’s books); your mindset also affects your motivation to learn. ()

Starting from the input/output functions in cstdio/iostream (the standard library) is a good choice, then learn and understand the following:

  1. Variable types
  2. Control statements
  3. Common algorithms (without a foundation, don’t get stuck hammering at what you don’t understand — this is a long-term process)
  4. Functions
  5. Classes and objects (C++) (from here on, it’s best to have an OOP mindset)
  6. Inheritance and polymorphism, plus the much-loved operator overloading (C++)
  7. Pointers (many people find this hard; it’s actually an address type with a specific type attached, used to point at the memory address of the corresponding variable)
  8. Strings and arrays (essentially just pointers)
  9. References (C++)
  10. Templates and other new features of C++11 (just getting a rough idea is fine)

Here I recommend reading C++ Primer Plus to start learning C++, and escape Lao Tan’s sea of suffering. (joking)

Then you can try to understand multithreading and mutual exclusion mechanisms, which helps a lot when switching to JavaScript and the like.

Things You Can Try Once You Have a C/C++ Foundation

Once you have a C/C++ foundation, learning new programming languages is far easier than learning with no foundation; you just need to know how these languages differ and what their features are.

For example, with a C/C++ foundation, I moved quickly and smoothly to Web-related languages like JavaScript and PHP.

You can also try GUI programming — jump out of the black-box terminal and step into the world of GUIs.

Give GUI a Try

Unlike the CLI, modern GUIs are usually message/event-driven and multithreaded. Here are some common GUI frameworks/libraries:

MFC

This is an ancient GUI library exclusive to Microsoft Windows; Wine on Linux can run most software built with it.

It’s essentially an object-oriented version of the WinAPI.

For historical reasons, MFC was tragically phased out (?), so I don’t recommend learning the MFC library.

Gtk

An open-source Widget (control) library for Linux, belonging to the GNOME camp.

Mainly developed in C, it has GObject, i.e. the GLib object system.

But there are ports to other platforms such as Win.

Qt

(pronounced cute) is a cross-platform, open-source (open source again!) C++ app development framework. Mainly used for writing GUI programs, it’s widely applied in all sorts of fields.

Whether you’re a beginner or a veteran, I recommend its bundled IDE: QtCreator.

It integrates all sorts of modules, though I once tried static compilation (MinGW+Qt5) and a Release executable was at least 17MB. (Big is good, big is beautiful) (joking)

It uses the easier-to-understand Signal/Slot mechanism to bind events such as button clicks and respond to them.

Try to Understand Operating System Libraries

For example the powerful and complex WinAPI, or Linux’s — but as a beginner, it’s best to build a solid foundation first and then look into these.

Closing

Learning to program is a long, gradual process, so don’t rush trying to become an expert overnight.
