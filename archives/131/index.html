How to Block IPs That Maliciously Log Into Your Server

Qijie
2023-05-11
Tech Notes
Linux, Server

Preface

Late at night our servers often get scanned by Nmap, and then a whole bunch of IPs probe and try to log into our servers. So how do we deal with a situation like this?

Requirements

Analyze the Linux system’s /var/log/secure security log file, and add the IP addresses of hackers or malicious login attempts that occur more than 20 times to the Iptables firewall blacklist;

Experimental Steps

  • First, look at the security log file
  • Print the IPs that failed to log in
  • Sort them and count the occurrences
  • Match IPs with more than 5 malicious logins
  • Loop over the matched results with a for loop, then write them into the firewall file

Conclusion

Ops security plays a very important role in real production environments. When we face hackers frantically scanning and probing, we need to block IPs the moment we see the traffic. Being able to block an IP quickly requires us to have a solid grasp of Linux commands, especially awk and sed. They are very common in our scripts, so you definitely need to master them.
