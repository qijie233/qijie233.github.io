Basic Syntax

Statements

C/C++ statements all end with a semicolon ;, don’t forget it~ (this also applies to languages like JS/Java/PHP)

What’s different from other languages is that you have to put your statements inside the int main() (by default; the specifics depend on the compiler) main function for them to actually run.

Assigning Values to Variables

Variable Types

Basic variable type keyword Description
int 32-bit integer
short 16~32-bit integer
long 32~64-bit integer
long long 64-bit integer
float 32-bit real number (that is, with a decimal point)
double 64-bit real number
char 8-bit single character
bool 1-bit boolean, only true (1) and false (0)
enum Enumeration, similar to int, but you can name integers
…… There are more basic types

Putting unsigned in front makes it unsigned, meaning the variable can only be 0 and positive numbers.

Only integer and character types can take unsigned.

Of course you can also define your own variable types; I’ll cover that in a later article.
