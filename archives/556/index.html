Qijie

Tech Notes
Linux, Server

What is tmux?

tmux is a CLI (command-line interface) application, and it can run several CLI applications at the same time. Each of those applications’ terminals is managed by tmux, and you can use tmux to access the terminals that are running — that’s terminal multiplexing.

Just like screen (some kid out there only knows how to use this to keep a Python app running, and doesn’t even use nohup), tmux can detach and attach (in plain words: send it to the background), but unlike screen, tmux lets you create, view, access and exit terminals more conveniently and intuitively.

That said, tmux’s default key bindings might feel a bit anti-human to beginners. (As anti-human as Blender’s keymap style — only good for its author’s habits.) But you get used to it. (And you can change them; if you couldn’t, not this many people would be using it.)

Starting from typing tmux Enter

This is the first screen you see


What greets your eyes is a sh waiting for you to respond. The observant ones will immediately notice the very conspicuous “taskbar”-like thing down at the bottom (officially called the status line).
This “taskbar” looks like you could click it with a mouse, and you actually can — it just needs a config file change (I’d still recommend the keyboard if possible, it’s more efficient).
At the bottom left, [0] is the session name, 0 by default, then 1 for the next one (incrementing), and of course you can customize it too (); “window” — anyone familiar with Win won’t be unfamiliar with this one, these windows just happen to take up the whole terminal.

The one with * is the current “window”, and the one with - is the previously visited “window”.
At the bottom right there’s the hostname wrapped in double quotes (hostname by default), plus the date and time.

Let’s start doing some tmux-specific operations

The following are all default key bindings.

Ctrl + B is the “opener” (I’ll use “the opener” in place of this combo below); its purpose is exactly to avoid key conflicts with all sorts of programs. (Though some people think “the opener” feels bad to press.)

After typing “the opener” on the keyboard, press ? (that’s Shift+/) and you’ll see the key binding help (in English)

Common “combos” What they do
“The opener” + c Create a new “window”
“The opener” + d detach (send to background); use tmux attach -t to come back to the foreground — of course tmux attach also returns to the most recently detached session
“The opener” + [ Use the arrow keys/PgUp/PgDn to move the cursor through the current terminal output; press Ctrl + c to return to normal
“The opener” + % Split left and right
“The opener” + “ Split top and bottom
“The opener” + arrows Switch the active “pane”
“The opener” + number Switch “window”
“The opener” + x Exit without leaving it in the background
“The opener” + q Show the numbers of the “panes”

And so on — for more “combos”, please refer to the official docs. (Actually the author is just too lazy to type them out)
