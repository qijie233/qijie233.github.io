Good News: Genshin Impact Now Runs on Linux

Qijie
2023-07-08
Tech Notes
Gaming, Genshin Impact, Linux

Let’s Get to Work!

First download the Genshin Impact installer:

Click me to go to the official site, hit "Download", and get the installer ready.

Step 1: Get into Steam


First go to “Library”, then follow the screenshots

Step 2: Install Genshin Impact

This step is very important!

Set compatibility to Proton 8.0 or above.

Then click “Play” to download Genshin Impact

You can do something else in the meantime, and once Genshin is downloaded, move on to the next step.

Step 3: Genshin Impact, Launch!

Try clicking this “Step 3”

Log in and enter the game just like you normally would playing Genshin on Windows

A note for those not using Proton

If, when logging in, the password field shows blank while you type instead of showing the word “Password”, that means the password has already been entered — much like a Linux terminal.

From now on you can play Genshin Impact on Linux~ (currently doing time in the Emblem domain)

Step 4: Set up the Genshin launcher

Find the Genshin launcher’s exe in [Steam installation directory]/steamapps/compatdata/[a string of digits]/pfx/ and fill it in as shown below under
Game Properties

Note: the path contains spaces, so it must be wrapped in ""! This is one of the Linux basics.

The string of digits: you can find it with find, Ctrl+F[Dolphin], or by sorting on time.

After that, clicking Play starts the Genshin launcher.

Misc

Running Genshin on Linux under the same conditions gives 20~30 more fps than on Windows, because DXVK is more efficient than DX11.

One user’s test result: Steam from Snap fails to launch Genshin about 99% of the time because the Snap container doesn’t have enough permissions (Error at hooking API “NtProtectVirtualMemory“).

These keybindings might be worth trying in Genshin:

Q Elemental Skill
R Elemental Burst
Ctrl Use Four-Leaf Sigils and the like
Tab Toggle walk/run (dive)
~ Wheel
Z Use the item in the bottom right corner
E Aim

Leave the rest at the default, so you don’t trigger your Burst by accident while exploring the overworld.
