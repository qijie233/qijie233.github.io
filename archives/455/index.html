TCP, Accelerate! BBR, Launch!

Qijie
2023-10-21
Tech Notes
Linux, Networking, Server

Preface

Did you know that slow download/upload speeds aren’t just about low broadband bandwidth (which you can only fix by throwing money at it)? Packet loss, device forwarding latency, and NIC bandwidth all affect it too. This article is mainly about mitigating the impact of packet loss and similar factors on download/upload speed to some extent.

What is BBR? BarBaRa, dazzling entrance! It’s actually a TCP congestion control algorithm developed by Google. The traditional TCP congestion control algorithm, Cubic, isn’t aware of current network conditions — it just fires packets blindly and retransmits whatever gets lost. That severely affects how fast packets are sent and received. BBR shifts from blindly firing packets to actively sensing the network and adapting its sending accordingly. It automatically adjusts the sending rate based on the current packet loss rate and bandwidth usage, and greatly increases packet throughput. This can reduce packet loss to some extent and saturate your bandwidth.

BBR has been built into Linux 4.9+, so any Linux kernel newer than 4.9 can enable it. Windows apparently has it too (?) but I don’t care.

Note: BBR only works for the TCP protocol; it has no effect at all on the UDP protocol. Playing games (most of them) / watching videos (some video streams send packets over UDP) and other situations that use the UDP protocol get no benefit from it.
