RVC Deployment, Inference and Training

Qijie
2024-04-12
Tech Notes
Deep Learning, Linux

Introduction

RVC stands for Retrieval-based-Voice-Conversion. It’s a voice changer based on VITS, and it’s often used together with UVR (for cover songs).

Requirements

It’s similar to SoVITS but much friendlier to junk machines (a 1650 still can’t really handle it). You can even use server CPUs — two “2690v2”s or a “2650v4” — and spend roughly two and a half days training a single model.

Inference needs at least 4GB of VRAM (in practice, 4GB of VRAM is just unbearable)

Training needs at least 6GB of VRAM

If you don’t have a graphics card, you can train at a snail’s pace on the CPU (a last resort)

Details

The factors that affect training/inference speed are:

  • CPU clock speed (if you’re using the CPU)
  • Number of CPU cores/threads (if you’re using the CPU) (smaller impact)
  • Memory frequency (if you’re using the CPU) (larger impact)
  • Number of CUDA cores on the graphics card (biggest impact)
  • VRAM frequency (moderate impact)
  • Amount of VRAM (biggest impact; you can adjust batch_size to speed up (?) training)

Inference

  1. Resampling — you generally leave this option alone and keep it at 0
  2. Just drag it to 1 without thinking
  3. Usually keep the default 0.33; pull it too small and it gets muddy
  4. Only effective with havest, generally leave it alone
  5. Depends on the quality of the model. If the model is good you can push it up to 0.8～0.98; if it isn’t, pull it down to 0.4～0.7. The 0.75 it usually gives you is also worth trying
  6. For male-to-female set it to 12, for female-to-male set it to -12, for the same gender just keep it at 0

Training

  1. If you have a graphics card choose rmvpe_gpu; if you don’t, choose rmvpe
  2. The save frequency should be a factor of the total number of training epochs
  3. This depends on how long the dataset is. For (5,10]min, [300,500] epochs is recommended; for >10min, [50,300). If you really don’t know how many epochs to train, go with 250 then
  4. For CPU training at least 8; for GPU training it depends on your VRAM. This determines how much VRAM/RAM it eats

Miscellaneous

wav and flac take up quite a lot of space, while mp3 eats up quite a lot of time

If a run doesn’t work out, you can tweak the parameters a bit and run it again

The quality of the original audio and of the model determines the ceiling of the final output
