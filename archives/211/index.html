How to Set Up a Virtual Machine — A Beginner-Friendly Tutorial

Qijie
2023-07-10
Tech Notes
Virtual Machine

What Is a Virtual Machine

Virtual machine, virtual machine — as the name suggests, it’s virtual. It’s isolated from the host machine’s system, and that way you can use a virtual machine to do a lot of interesting things, like running viruses or doing things where you’re afraid of catching a virus. Of course, a virtual machine’s uses go far beyond that.

About virtual machine software
There are a lot of virtual machine programs; the common ones are VM VirtualBox, VMware and the hyper-v that comes with Windows, so this article will use the most commonly used one, VMware, as the virtual machine software for the tutorial.

Installing the Virtual Machine Software

There’s not much to say about this step — just click Next mindlessly.

Creating a Virtual Machine

One

This is the interface you get after opening it. If you’re a normal person you should be able to see 创建新的虚拟机; if you can’t find it, please close this tutorial immediately and take your medical insurance card to the ophthalmology department at the hospital.

Two

For this step we choose Typical. Don’t ask me why we don’t choose Custom — look at the title of the article and you should know.

Three

Next, we choose 安装程序系统镜像文件; for this step you select the ISO system image file you downloaded yourself. Here I’m sharing the systems from my own download site with everyone[button color=”info” icon=”” url=”https://share.qijieya.cn/%E7%B3%BB%E7%BB%9F“ type=”round”]Systems[/button]

Four

For this step, do as you see fit: the Windows product key can be left blank and activated after the system is installed, the Windows edition is your choice, and personalizing Windows is up to you.

Five

Fill in the virtual machine name yourself. The install location defaults to the C drive; I don’t recommend C, put it on D. I’ve changed my own preferences, so mine defaults to D.

Six

The disk size depends on your hard drive size or on what you need from the virtual machine (what you’re going to do). I suggest choosing 将磁盘储存为单个单位 (after the virtual machine’s system is installed there’s just one disk).

Seven

This step normally doesn’t need any changes (actually you can make the memory bigger, otherwise it’ll be laggy). If your computer is beefy enough, you can choose Customize Hardware[font color=”#DC143C”]Note!!![/font] The memory you choose must not exceed half of your own computer’s memory. For the CPU setting, use your own judgment — choose too much and the host computer’s CPU usage goes up.

Eight

Once it’s created, click “Turn on this virtual machine” (if in the previous step you ticked “Create and start this virtual machine”, it will boot automatically after creation).

Nine

After it boots, click on the virtual machine’s screen so that keyboard and mouse input goes to the virtual machine. When you see the prompt in the picture below, quickly press the spacebar to enter the system installation, and once the familiar win10 LOGO appears you’ll know it worked.

Ten

Installing the system: just click Next mindlessly. At the step shown below, choose 我没有产品密钥

Then choose the system you want to install, click Next, accept the license terms, and at the step shown below choose 自定义

Next is hard drive partitioning: click New, then Apply; after clicking, another window pops up, click OK again.

Choose the largest partition to install the system on, then click Next.

Then just wait for the system installation to finish and you’re done.

Closing Words

And with that, the virtual machine creation tutorial comes to an end. This virtual machine software has plenty more features — take your time exploring them yourselves.
