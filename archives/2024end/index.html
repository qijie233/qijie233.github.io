Bits and Pieces, Another Year? 2024 Year-End Recap

Qijie
2024-12-22
Life & Misc › Reflections
Daily Life, Recap

2024 is almost over🎉, and it's time for Qijie's annual year-end recap again (a boring play-by-play). This year is one worth remembering, too

A Rough Summary of the Things I Did This Year

I feel like this year was a bit fuller? Maybe because I went to more anime conventions this year, and also because someone likes me now?

About the Website & Projects

Tianyi Forum

Together with friends I founded the country's first Chinese Vocaloid forum, i.lty.fan

I'm also lucky to have met these friends. I can't really contribute much — a lot of the time I'm basically just a mascot — but meeting them was fate

Registered users are already approaching 10k now

Anime Conventions

I quite like going to conventions

Someone with no place in everyday life, at a convention I'm no longer bound by the shackles in my own mind — I can be myself all I want, and become whoever I want to be. At a convention everyone shares my interests, and I can chat naturally with most people; that's another reason I like conventions so much

But for me, sometimes I really envy the people at conventions who have friends and family there with them. I can only envy them secretly. I have no close companions, and almost no true friends, and I can't find anyone to share that feeling in my heart with

Conventions I went to this year

  • Honkai: Star Rail Carnival (5.1)

  • BilibiliWorld (7.12)

  • CP30 (10.4)

  • Nanjing · PT04ACGame Carnival (12.28)

Cost Control

  • Every year, when I carefully add up what I spend on websites, it's still quite a lot; at the start of 2024 I began to cut costs

  • My personal landing page is deployed on Vercal with a custom domain bound to it.

  • Moved the QQBOT service to the home cloud, so it no longer takes up cloud service resources

  • The MC server sits in the home cloud, no longer using cloud services, with players connecting via IPv6 + tunneling

  • Used two Alibaba Cloud accounts to buy 99-plan servers separately, one in Hangzhou and one in Shanghai

  • After the Huawei Cloud CDN expired, I used Volcano Engine CDN to accelerate the static site and the blog, while the other sites use the free quotas from Upyun and DogeCloud

Changes

  • Changed the blog framework from Typecho to Halo; the new framework brings a smoother experience and more room for feature extensions.

  • Dedicated the Shanghai server to running the blog and its comment section alone, while the rest is in Hangzhou

  • Replaced all the static assets that were originally local in the blog with cloud resources, stored in Alibaba Cloud OSS and accelerated with Volcano Engine CDN

Home Cloud

  • Bought a mini PC and used Fnos as the NAS system for home photo backups, with 1.5TB of usable space

  • Bought a 2.5-inch Seagate 1T drive for the upgrade

  • Runs the MC plugin server

  • Runs the NetEase Cloud Music API (locally)

  • Runs QQBot

Hopes for Next Year

Priorities

  • Get into a better school

  • Have someone to go to conventions with me

  • Improve the blog's content

  • Start my own company

  • Depression gets a bit better

LAN Cloud

  • At home I'm currently using a Lenovo mini PC as the main machine; its flexibility and expandability are very low

  • Buy a 2U server to use as the intranet server

  • Expand the LAN cloud storage space, so storing anime is more convenient

  • Get China Unicom gigabit broadband for the home cloud (among the big three carriers, Unicom can provide a dynamic public IP)

  • Refactor the home network layout

  • Use optical networking as much as possible to boost network speed

  • Add new backups for important data
